01 / Game Pass

Как создать Game Pass

Game Pass используется для продажи доступа или специальных возможностей внутри твоей игры.

01

Открой Creator Hub

Перейди в официальный Roblox Creator Hub и войди в свой аккаунт.

Открыть Creator Hub ↗
02

Выбери свою игру

Открой раздел Creations, выбери нужный Experience и перейди в управление игрой.

03

Открой Monetization

В меню игры найди раздел Monetization → Passes.

04

Создай Pass

Нажми Create a Pass. Добавь изображение, название и описание, затем создай Pass.

Create a Pass
05

Скопируй ID

После создания открой меню Pass ⋯ и выбери Copy Asset ID.

Copy Asset ID
Важно: игра должна быть опубликована и доступна, чтобы создавать для неё Pass.
02 / Code

Как применить код

Подарочные карты и некоторые другие Roblox-коды активируются через официальный сайт Roblox.

01

Открой страницу активации

Используй официальный сайт Roblox для активации кода.

Открыть Roblox Redeem ↗
02

Войди в аккаунт

Авторизуйся именно в том Roblox-аккаунте, на который хочешь получить содержимое кода.

03

Введи код

Вставь полученный код в специальное поле и нажми кнопку Redeem.

04

Готово

Если код действителен, Roblox покажет подтверждение его активации.

Совет: используй только официальный сайт Roblox для ввода кодов и данных аккаунта.
